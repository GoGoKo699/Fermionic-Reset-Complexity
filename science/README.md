# Science map

The task is reset to the vacuum of all input modes through one Markovian loss port. Both control classes include input-independent randomness and are tested against arbitrary reference correlations.

Read the model, Gaussian cooling bound and universal frontier in sequence. The interacting proof then gives two finite schedules for different regimes. The tree controls the action uniformly in size and accuracy. The cycle attains the fixed-size high-action exponent.
